# EZVIZ camera video downloader landing page

Live site: https://sneggoroddd.github.io/ezviz-camera-video-downloader/

Static Russian and English landing page for [@EZVIZ_download_bot](https://t.me/EZVIZ_download_bot). Published with GitHub Pages from the `main` branch root.

## Pages

- `/` — Russian
- `/en/` — English

The page is independent of EZVIZ. It describes the Telegram bot's current limits: up to three cameras, up to three days per request, and ZIP files of up to 45 MB. The illustrative artwork was supplied by the project owner.

## Search terms

The titles and visible copy target the specific task: “скачать видео с камеры EZVIZ”, “EZVIZ с карты памяти / SD-карты”, “download EZVIZ camera videos from SD card”, and “EZVIZ Telegram bot”. The site includes localized URLs, reciprocal `hreflang`, canonical URLs, a sitemap, and `robots.txt`. Search ranking and indexing depend on Google and are not guaranteed by these files.

To preview locally, serve this folder with any static HTTP server, for example `python3 -m http.server 8000`, and open `http://localhost:8000/`.
